# 需求文档：workspace-allowed-roots

## 功能概述

为每个 MCP 工作区增加显式的外部允许根目录配置，使工作区内的符号链接可以安全指向录制数据等已授权的物理目录，同时继续拒绝未授权路径和外部写入。

## 范围边界

**In Scope**

- RuntimeConfig 持久化 `allowed_roots`。
- MCP 读路径解析允许主工作区和配置的外部根目录。
- 写路径仍只能落在主工作区。
- 策略界面支持多行绝对路径配置。
- 旧配置缺少该字段时保持原有行为。

**Out of Scope**

- 任意主机路径执行。
- Actions 服务放宽路径边界。
- Xvast GUI 控制或浏览器桥接替代。

## 需求列表

### FR-1：配置允许根目录

**优先级:** Must

MCP 工作区 SHALL 支持零个或多个显式配置的绝对目录；目录必须存在且 canonicalize 后仍是目录。

### FR-2：安全读取

**优先级:** Must

当读取路径解析到主工作区或任一允许根目录时，系统 SHALL 允许读取；解析到其他目录时 SHALL 返回路径安全错误。

### FR-3：写入隔离

**优先级:** Must

即使外部目录被允许读取，写入工具 SHALL 仍只能写入主工作区。

### FR-4：界面与兼容

**优先级:** Should

策略界面 SHALL 支持每行一个绝对路径；旧配置反序列化时 SHALL 默认为空列表。

## 非功能需求

- 安全：不得通过配置获得任意 `host` 执行能力。
- 兼容：现有工作区配置无需迁移即可启动。
- 可验证：提供允许读取、拒绝未授权读取和拒绝外部写入测试。

## 依赖关系

- 依赖现有 Workspace 路径解析与 RuntimeConfig 持久化机制。
- 依赖 MCP listener 使用 RuntimeConfig 启动服务。
- 不依赖浏览器桥接，也不改变 Xvast 或原生 CUA 能力。
