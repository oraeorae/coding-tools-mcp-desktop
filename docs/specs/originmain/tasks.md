- **预计新建规格文件数**：3 个
- **上游净差异文件数**：141 个

### 阶段 1：准备工作

- [ ] 1.1 固定上下游引用并建立可恢复的分支与 stash
  - **证据块**：`git rev-list --left-right --count HEAD...origin/main` 显示本地 12、上游 21；`git status --short` 显示已有用户改动。
  - **涉及文件**：Git refs 与 stash，不直接修改生产文件。
  - _需求：FR-1_ ｜ _设计：技术方案_
- [ ] 1.2 运行图谱影响分析并登记高风险集成轴
  - **证据块**：`call_tool` 影响 Tools/Actions；listener 存在两个同名入口；RuntimeSupervisor 图谱结果为 UNKNOWN，必须结合文本调用点核验。
  - **涉及文件**：`src-tauri/src/tools/dispatch.rs`、`mcp/listener.rs`、`actions/listener.rs`、`runtime/supervisor.rs`。
  - _需求：FR-1、FR-2_ ｜ _设计：架构设计_

### 阶段 2：核心集成

- [ ] 2.1 合并固定上游 SHA 并逐文件语义解决冲突
  - **证据块**：上游新增审计、上游 MCP、FRP TLS 和扫描加固；本地新增 browser/PDF/updater/request log/shutdown/allowed roots/research。
  - **涉及文件**：Git 冲突清单中的文件；单个超 500 行模块按现有模块边界保留，不做无关重构。
  - _需求：FR-1、FR-2_ ｜ _设计：主要集成轴_
- [ ] 2.2 恢复合并前工作树并处理与上游合并结果的二次冲突
  - **证据块**：stash 清单和恢复后的 `git status --short` 必须可追溯。
  - **涉及文件**：合并前已修改和未跟踪文件。
  - _需求：FR-1、FR-2_ ｜ _设计：决策 2_
- [ ] 2.3 核验版本、配置模型、工具目录和 macOS 打包声明
  - **证据块**：本地版本 0.3.7；上游版本 0.2.4；现有连接器目录为 30 个工具。
  - **涉及文件**：版本文件、`workspace/model.rs`、`tools/registry.rs`、`Info.plist`、`Entitlements.plist`。
  - _需求：FR-2_ ｜ _设计：API 设计、数据模型_
